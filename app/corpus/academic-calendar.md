## Enrollment System
UCSC uses a **two-pass enrollment system**:
- **Pass 1:** Enroll in up to half your expected units (priority based on class standing)
- **Pass 2:** Fill remaining units
- **Pass 3 (Open Enrollment):** First-come, first-served for remaining seats

Enrollment appointment times are based on:
1. Class level (seniors first → freshmen last)
2. Number of units completed
3. Random assignment within each priority group
